# Trishul AI – STEM Racing knowledge pack

This file documents the curated local knowledge used by `src/knowledgeBase.ts`.

## Coverage

- STEM Racing / F1 in Schools overview and India competition pathway
- Aerodynamics, drag, lift and downforce
- CAD, CAM, CFD, CNC and 3D printing
- Assembly, fit, tolerances, inspection and quality control
- Testing, iteration and performance improvement
- Engineering portfolios, project management, enterprise and sponsorship
- Pit displays, presentations, regulations and responsible AI use
- Supporting physics concepts: Newton's laws, speed, acceleration, friction, rolling resistance, mass and centre of gravity

## Source hierarchy and limitations

1. **STEM Racing Global official resources**: current learning resources, software links, project management handbook, AI guidance and World Finals regulations. The page currently lists 2026 World Finals documents. Those documents are not automatically the rules for an Indian Regional event.
2. **STEM Racing Global downloads**: official downloadable resources including decals, model-block and PowerPack references, class-labelled scrutineering gauges, and manufacturing tool data.
3. **STEM Racing India / STEMplify programme pages**: programme overview and published competition pathway information. The 2025–26 course page lists competition regulations, technical regulations, annexures and event announcements, but the course content is access-restricted. The app does not claim to have read those locked documents.
4. **OpenStax University Physics, Volume 1**: background explanations for general mechanics concepts.

## Important rule for Trishul AI

For a question about whether a car feature is legal, exact dimensions, portfolio page limits, judging points, dates, deadlines or event procedures, the assistant must direct the team to the current STEM Racing India event documents and supervising organiser. Never treat a Global World Finals rule, a UK rule, or an old season's Indian rule as automatically applicable to the current Indian Regional competition.

## AI limitations in this build

This is a local searchable knowledge base with curated explanations and keyword matching. It is not a trained model and it is not connected to a live generative AI service. It can answer the topics listed above and use the app's saved team data for supported dashboard questions. For arbitrary open-ended questions, current news, or topics not represented here, a secure server-side AI integration and retrieval system would be needed.
